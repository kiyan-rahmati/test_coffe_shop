# ☕ Naroon Cafe | کافه نارون رشت

سایت فروشگاهی کافه با **۵ تم کاملاً متفاوت**، آهنگ مخصوص هر تم، خوش‌آمدگویی بر اساس شغل بازدیدکننده، سبد خرید، ثبت سفارش، داشبورد کاربر و پنل ادمین برای ویرایش قیمت‌ها.
بدون دیتابیس؛ فرانت‌اند کامل (HTML/CSS/JS خالص) + بک‌اند اختیاری PHP/AJAX با ذخیره در فایل JSON.

> A multi-theme coffee-shop storefront for Naroon Cafe (Rasht, Iran). Pure HTML/CSS/JS front-end, optional PHP/AJAX backend (JSON file storage, no database). MIT licensed.

## ✨ امکانات

- **۵ تم:** قهوه‌خانه‌ای (دود قلیان + «خوش اومدی مشتی»)، کافی‌شاپ رسمی، سفارش آنلاین (حال‌وهوای اپ پیک)، سایبرپانک (نئون و باران ماتریسی)، پوستر (طرح ویژه)
- **متن‌های متفاوت برای هر تم** با یک پیام مشترک
- **۵ آهنگ** (یکی برای هر تم) با پخش/توقف، قبلی/بعدی و کنترل صدا
- **پرسیدن شغل** در ورود و خوش‌آمدگویی مخصوص (مهندس، اوستا، دکتر، استاد و ۴۰ شغل دیگر)
- منوی کامل با دسته‌بندی و جستجو، سبد خرید، سفارش (حضوری / بیرون‌بر / ارسال)
- ثبت‌نام و ورود، **داشبورد** (سفارش‌ها، تغییر تم، رنگ، اندازه نوشته، پروفایل)
- **پنل ادمین** در پوشه‌ی `admin/` (ویرایش قیمت و منو، مدیریت وضعیت سفارش) — ورود پیش‌فرض: `admin` / `admin`
- نقشه‌ی Google Maps کافه نارون رشت
- ریسپانسیو، قابل استفاده با کیبورد، احترام به `prefers-reduced-motion`

```
naroon_coffe/

├─ assets/
│  ├─ css/                 base.css (ساختار) + themes.css (۵ تم)

└─ LICENSE                 MIT
```

## 🚀 دو نسخه

### ۱) نسخه‌ی استاتیک (GitHub Pages)
بدون بک‌اند. کاربران، سفارش‌ها و تغییرات ادمین در **localStorage مرورگر** ذخیره می‌شوند (مناسب دمو و پورتفولیو).
1. در گیت‌هاب: `Settings → Pages → Deploy from a branch → main / (root)`
2. آدرس: `https://kiyan-rahmati.github.io/naroon_coffe/`

سایت خودش تشخیص می‌دهد بک‌اند وجود ندارد و در حالت استاتیک کار می‌کند.

### ۲) نسخه‌ی کامل با PHP + AJAX (روی سیستم یا هاست)
نیازمند PHP ‏۷.۴ به بالا. دیتابیس لازم نیست؛ داده‌ها در `backend/data/*.json` ذخیره می‌شوند.
```bash
git clone https://github.com/kiyan-rahmati/naroon_coffe.git
cd naroon_coffe
php -S localhost:8000 router.php
```
بعد باز کنید: `http://localhost:8000` و پنل ادمین: `http://localhost:8000/admin/`

در این حالت سایت خودکار به API وصل می‌شود (حساب‌ها، سفارش‌ها و قیمت‌ها روی سرور و مشترک بین همه).

## ⚙️ شخصی‌سازی

| چه چیزی | کجا |
|---|---|
| منو، قیمت اولیه، تم‌ها و متن‌ها، شغل‌ها | `assets/js/data.js` |
| آدرس نقشه | `config.mapQuery` در `data.js` |
| آهنگ‌ها | فایل‌های `assets/audio/*.mp3` را عوض کنید (نام‌ها یکی بماند) |
| رنگ و ظاهر هر تم | `assets/css/themes.css` |
| رمز ادمین (PHP) | `backend/config.php` |

## 🔐 امنیت (حتماً بخوانید)

رمز پیش‌فرض ادمین `admin/admin` است و فقط برای دمو مناسب است. **قبل از انتشار روی سرور واقعی** در `backend/config.php` رمز را عوض کنید. در نسخه‌ی استاتیک (GitHub Pages) هر بازدیدکننده می‌تواند کد را ببیند؛ پس آن نسخه امنیت واقعی ندارد و فقط نمایشی است. جزئیات: [SECURITY.md](SECURITY.md)

## 🎵 درباره‌ی آهنگ‌ها

آهنگ‌های داخل پروژه، لوپ‌های کوتاهِ ساخته‌شده با کد هستند و مشکل کپی‌رایت ندارند. اگر آهنگ واقعی (مثلاً قهوه‌خانه‌ای یا لاتی) می‌گذارید، مطمئن شوید حق استفاده از آن را دارید.
